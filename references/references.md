# References

## Graph Theory and Network Applications

### Viral Variant Detection Using Graph Communities

Mohebbi, F., Zelikovsky, A., Mangul, S., Chowell, G., & Skums, P. (2024).
"Early detection of emerging viral variants through analysis of community
structure of coordinated substitution networks."
*Nature Communications, 15*, 2838.
https://www.nature.com/articles/s41467-024-47304-6

**Topics**: Graph theory, network analysis, community detection, dense subgraphs,
computational biology, viral evolution

**Used in:** Broader motivation / real-world applications of graph algorithms

**Notes:** Demonstrates how viral mutations can be modeled as vertices in a
coordinated substitution network, with statistically significant co-occurrence
relationships represented as edges. Dense communities are then analyzed to
identify potentially emerging viral haplotypes.

## Algorithms and Data Structures

### Introduction to Algorithms

Cormen, T. H., Leiserson, C. E., Rivest, R. L., & Stein, C. (2009).

*Introduction to Algorithms* (3rd ed.).

MIT Press.

[Introduction to Algorithms — Third Edition](https://www.cs.mcgill.ca/~akroit/math/compsci/Cormen%20Introduction%20to%20Algorithms.pdf)

**Topics:** Graph theory, breadth-first search, depth-first search, topological sorting, heaps, priority queues, shortest paths, Dijkstra's algorithm, minimum spanning trees, disjoint sets, algorithm analysis

**Used in:** Foundational study and reference material for the graph theory and algorithm sections of this repository

**Notes:** Used as a primary textbook reference while studying the theoretical foundations, correctness, complexity, and implementation principles behind the graph algorithms covered in this repository. Relevant material is studied alongside my own notes and implementations rather than reproduced directly.
