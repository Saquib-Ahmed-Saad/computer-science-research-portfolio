# Survey of Path Planning Algorithms

Alexander, A., Venkatesan, K., Mounsef, J., & Ramanujam, K. (2025).

"A Comprehensive Survey of Path Planning Algorithms for Autonomous Systems and Mobile Robots: Traditional and Modern Approaches."

*IEEE Access, 13*, 176287-176326.

[IEEE Xplore - A Comprehensive Survey of Path Planning Algorithms for Autonomous Systems and Mobile Robots](https://ieeexplore.ieee.org/document/11195089)

**Topics:** Path planning, graph search, breadth-first search, depth-first search, Dijkstra's algorithm, A*, Bellman-Ford algorithm, bidirectional search, static environments, dynamic environments, algorithm evaluation, benchmarking

**Used in:** Literature review and experimental methodology for the graph search algorithm comparison project

**Notes:** Systematic survey of traditional and modern path planning approaches for autonomous systems and mobile robots. Particularly relevant to this research because it discusses several graph search algorithms studied in this repository and examines performance criteria such as computation time, path optimality, computational resources, and scalability. The survey is also used to identify prior experimental studies and benchmarking approaches that may help inform the design of the graph search comparison experiments.
