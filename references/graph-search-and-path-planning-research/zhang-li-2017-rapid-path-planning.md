### Rapid Path Planning in Dynamic Environments

Zhang, H., & Li, M. (2017).

"Rapid Path Planning Algorithm for Mobile Robot in Dynamic Environment."

*Advances in Mechanical Engineering, 9*(12), 1-12.

[Rapid Path Planning Algorithm for Mobile Robot in Dynamic Environment](https://journals.sagepub.com/doi/epub/10.1177/1687814017747400)

**Topics:** Path planning, graph search, Dijkstra's algorithm, A* search, D* search, dynamic environments, local re-planning, rolling window, experimental algorithm comparison, performance evaluation

**Used in:** Literature review and experimental methodology for the graph search algorithm comparison project

**Notes:** Proposes a rapid path planning method that combines Dijkstra's algorithm for global preprocessing with A* for local re-planning in dynamic environments. The proposed method is experimentally compared with ACO, A*, and D* using path length, preprocessing time, number of re-planning events, and average re-planning time. Additional experiments evaluate the algorithms across multiple start-goal configurations in a larger simulated environment. Particularly useful to this project as an example of controlled empirical algorithm comparison, multi-metric performance evaluation, and analysis of computational trade-offs.
