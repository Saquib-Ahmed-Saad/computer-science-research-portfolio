# Complete Coverage Path Planning for Reconfigurable Robots

Cheng, K. P., Mohan, R. E., Nhan, N. H. K., & Le, A. V. (2019).

"Graph Theory-Based Approach to Accomplish Complete Coverage Path Planning Tasks for Reconfigurable Robots."

*IEEE Access, 7*, 94642-94657.

[IEEE Xplore - Graph Theory-Based Approach to Accomplish Complete Coverage Path Planning Tasks for Reconfigurable Robots](https://ieeexplore.ieee.org/document/8761971)

**Paper:** https://ieeexplore.ieee.org/document/8761971

**Topics:** Graph theory, complete coverage path planning, robotics, graph partitioning, recursive backtracking, Dijkstra's algorithm, dynamic programming, memoization, reconfigurable robots

**Used in:** Real-world graph applications and supporting literature for the graph search algorithm comparison project

**Notes:** Applies graph theory to complete coverage path planning for a self-reconfigurable robot. The workspace is represented as a graph containing multiple robot morphology layers and is partitioned into smaller stripe-layer subgraphs. Recursive backtracking is used for coverage search within smaller regions, while dynamic programming and memoization reduce repeated computation. Dijkstra's algorithm with a priority queue is applied to an auxiliary graph to determine a minimum-action-cost route between stripe-layer solutions. The paper also evaluates different starting-variable configurations using complete coverage, action cost, and coverage overlap-related measures.
