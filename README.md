# Independent Computer Science Research Portfolio

**Research Focus**

Experimental Analysis of Graph Search Algorithms Across Different Graph Structures

---

## About

This repository documents my independent study in computer science as I prepare for graduate-level research. Rather than serving as a collection of coding exercises, it is designed as a structured learning portfolio that combines theoretical understanding, algorithm implementations, research questions, and experimental planning.

Each topic is studied through four stages:

- Learning the underlying theory
- Implementing the algorithm in Python
- Answering research questions
- Preparing for experimental evaluation

The long-term objective is to develop the knowledge and methodology required to conduct undergraduate research in graph algorithms and pursue graduate studies in computer science.

---

## Current Research Focus

My current research explores the experimental comparison of graph search algorithms across different graph structures.

Algorithms currently being studied include:

- Graph Theory Fundamentals
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Heaps & Priority Queues
- Topological Sorting
- Dijkstra's Algorithm
- A* Search

Future work will include:

- Minimum Spanning Trees
- Union-Find (Disjoint Set Union)
- Bellman-Ford
- Floyd-Warshall
- Network Flow Algorithms
- Advanced graph optimization techniques

## Learning Methodology

Each algorithm follows a consistent structure:

- Conceptual overview
- Theory and intuition
- Python implementation
- Code walkthrough
- Complexity analysis
- Applications
- Limitations
- Research questions
- Interview questions

This approach emphasizes understanding the reasoning behind each algorithm rather than simply memorizing implementations.

---

## Research Methodology

For each topic, I:

1. Study the theoretical foundations using textbooks and educational resources.
2. Implement the algorithm in Python from scratch.
3. Answer conceptual and research-oriented questions in my own words.
4. Compare algorithms through experimental evaluation.
5. Document findings and future research ideas.
